请仔细分析以下所有附件图片，识别每个附件属于哪种材料类型。

## 可用材料类别
$(material_list)

## 任务要求
1. 为每个附件图片识别其材料类型
2. 提取关键信息用于后续归集判断
3. 说明分类的理由。

## 输出格式
请以JSON格式返回，格式如下：
```json
{
  "attachments": [
    {
      "file_name": "附件文件名",
      "material_type": "材料类型（必须从上述材料类别中选择）",
      "key_info": "关键识别信息（如文档标题、编号等）",
      "reason": "分类理由"
    }
  ]
}
```

## 注意事项
- material_type 必须严格从上述材料类别列表中选择
- 如果无法确定，使用"其他"
- key_info 应包含有助于后续归集的关键信息
- 每个附件都必须有对应的分类结果
