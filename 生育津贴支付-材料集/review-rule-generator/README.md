# 审查规则JSON生成器

从 `factors.xlsx` 的审查要点列自动生成符合导入规范的审查规则 JSON 文件。

## 功能

- 读取 `factors.xlsx` 中的审查要点名称、审查要点规则说明等列
- 自动推断审查规则类型（规则对比 / 大模型 / Groovy脚本）
- 解析 `#材料名称-字段名称#` 格式的要素引用，转换为 `$材料:字段$` 占位符
- 支持 LLM 增强推理（可选，需配置 API Key）
- 输出符合导入规范的 JSON 文件

## 推断逻辑

| 情形 | 推断类型 |
|------|---------|
| 规则说明含 `#材料-字段#` 引用 + 明确比较词（一致/等于/包含等） | `review_rule="2"` 规则对比 |
| 规则说明含 `#材料-字段#` 引用 + 复杂算法词（计算/天数/正则等） | `review_rule="3"` Groovy脚本 |
| 无明确引用或模糊描述 | `review_rule="1"` 大模型 |

## 用法

```bash
# 基本用法（本地推断）
python3 generate_review_rule.py <材料集目录>

# 启用LLM增强推理
python3 generate_review_rule.py <材料集目录> \
  --use-llm \
  --api-key YOUR_API_KEY \
  --base-url https://api.openai.com/v1 \
  --model gpt-4o-mini
```

## factors.xlsx 格式要求

支持含以下列的梳理表格式（扩展格式）：

| 列名 | 说明 |
|------|------|
| 材料名称 | 审查材料名称（支持合并单元格向下继承） |
| 审查要点名称 | 要点名称，为空则跳过 |
| 审查要点规则说明 | 规则描述，用 `#材料名称-字段名称#` 引用要素 |
| 审查通过标准回答 | 通过原因模板（可选） |
| 审查不通过标准回答 | 不通过原因模板（可选） |
| 排序号 | 排序（可选） |
| 排他情形 | 排除情形表达式（可选） |

## 输出

每个材料生成一个 JSON 文件：`{材料名}--审查规则导入.json`

- 若材料子目录存在，输出到子目录中
- 否则输出到工作目录根目录

## 模板文件

- `templates/rule1_llm.json` — 大模型模式模板
- `templates/rule2_compare.json` — 规则对比模式模板
- `templates/rule3_groovy.json` — Groovy脚本模式模板
