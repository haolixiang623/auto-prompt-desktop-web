# 智能文档要素提取提示词生成器

此 Skill 使用 AI 智能分析实际文档内容，自动生成精准的要素提取提示词，而不是使用通用的"提取XX，保持原格式"这类泛泛描述。

## 🎯 核心优势

**传统方式**：手动编写"提取统一社会信用代码，保持原格式"
**智能方式**：AI 分析后生成"识别为18位由数字和大写字母组成的字符串，其中第18位为校验码（可能为字母X），通常以'91'开头，且在文档中常位于企业信息区域的显著位置"

## �️ 案例库系统

系统内置**智能案例库**，自动积累和复用优质提取规则：

1. **智能匹配**：Qwen 自动分析要素与案例库的相似度，优先使用已验证的规则
2. **自动积累**：验证通过的 AI 生成规则自动保存到案例库（标记来源：`ai_generated`）
3. **手动案例**：预置常见要素规则（标记来源：`manual`）
4. **混合模式**：匹配到的用案例库，未匹配的用 AI 生成

**优势**：
- ✅ 减少 AI 调用次数，提升生成速度
- ✅ 保证规则一致性和质量
- ✅ 持续学习，越用越智能

##  智能工作流程

1. **读取要素信息**：从 `factors.csv` 读取要素名称及上下文说明
2. **加载案例库**：加载 `case_library.json` 中的历史优质规则
3. **智能匹配**：Qwen 分析要素与案例库的相似度，匹配已有规则
4. **AI 补充生成**：对未匹配的要素，Qwen 分析图片并生成新规则
5. **组装提示词**：将规则（案例库+AI生成）替换 `template.txt` 中的 `$(factors)` 占位符
6. **验证效果**：使用生成的提示词验证提取效果
7. **自动积累**：验证通过的新规则自动保存到案例库

## 文件结构要求

在使用此 Skill 的目录下需要包含以下文件：

```
目录名称/
├── factors.csv          # 要素定义文件（必需）
├── template.txt         # 提示词模板（可选，不存在则使用默认模板）
└── *.jpg/png/bmp       # 待验证的图片附件（必需）

.windsurf/skills/doc-extract-prompt-gen/
├── generate_prompt.py   # 生成脚本（统一位置）
├── case_library.json    # 案例库文件（所有目录共享）
├── template.txt         # 默认提示词模板
└── run.sh              # 便捷启动脚本
```

### factors.csv 格式（增强版）

CSV 文件包含**三列**，为 AI 提供上下文信息以生成更精准的提取规则：

| 列名 | 说明 | 示例 |
|------|------|------|
| 要素名称 | 需要提取的要素名称 | 统一社会信用代码 |
| 要素提取说明 | 该要素的业务含义或用途 | 企业的唯一识别码 |
| 提取规则说明 | 该要素的格式特征提示 | 18位字母数字组合 |

**示例 CSV 内容**：
```csv
要素名称,要素提取说明,提取规则说明
统一社会信用代码,企业的唯一识别码,18位字母数字组合
企业名称,公司的完整法定名称,包含公司类型后缀
注册资本,企业注册时的资本金额,包含金额和币种
成立日期,企业正式成立的日期,日期格式
```

**优势**：
- ✅ AI 结合你的说明和实际图片内容生成更精准的规则
- ✅ 提取说明帮助 AI 理解业务含义
- ✅ 规则说明提示 AI 关注特定格式特征

### template.txt 格式（可选）

**默认模板**：skill 目录提供了标准的提示词模板，适用于大多数文档要素提取场景。

**自定义模板**：如果需要特殊的提示词格式，可以在工作目录创建 `template.txt`，系统会优先使用自定义模板。

**模板要求**：
- 必须包含 `$(factors)` 占位符，用于插入生成的要素列表
- 可以自定义角色指令、输出格式等

**示例模板**：
```
# 角色与核心指令
你是一个高精度的文本提取器...

# 识别要素列表及规则
$(factors)

# 输出格式要求
请严格按照以下JSON格式输出...
```

**模板优先级**：
1. 工作目录的 `template.txt`（如果存在）
2. skill 目录的默认 `template.txt`

### case_library.json 格式（自动管理）

**重要**：案例库文件统一保存在 skill 目录（`.windsurf/skills/doc-extract-prompt-gen/case_library.json`），所有工作目录共享同一个案例库。

案例库文件会自动创建和更新，无需手动编辑。每个案例包含：

```json
{
  "version": "1.0",
  "cases": [
    {
      "factor_name": "统一社会信用代码",
      "extract_desc": "企业的唯一识别码",
      "rule_desc": "18位字母数字组合",
      "extraction_rule": "在文档中识别18位...",
      "format_requirement": "保持原格式...",
      "source": "manual",  // 或 "ai_generated"
      "created_at": "2026-02-26",
      "tags": ["企业信息", "营业执照"]
    }
  ]
}
```

**来源标记**：
- `manual`：手动预置的优质案例
- `ai_generated`：AI 生成并验证通过的案例
- `imported`：通过 `case-import` skill 批量导入的案例

**批量导入案例**：
使用 `case-import` skill 可以从 `case-collect` 目录批量导入已生成的提示词文件到案例库。详见 `case-import` skill 文档。

# 识别要素列表及规则

## 智能分析流程

脚本会自动执行以下智能分析：

### 步骤 0：案例库匹配（新增）
- Qwen 分析要素描述与案例库的语义相似度
- 自动匹配已验证的优质规则
- 显示匹配结果：`[案例库] ✓ '统一社会信用代码' 匹配到案例库中的 '统一社会信用代码'`

### 步骤 1：AI 识别要素（按需）
- 仅对未匹配的要素执行
- Qwen 分析图片，识别每个要素的实际内容和特征

### 步骤 2：AI 生成规则（按需）
- 基于识别结果，Qwen 自动生成：
  - **提取规则**：具体描述如何识别（基于内容特征、位置、格式等）
  - **格式要求**：明确的格式处理规则（而非泛泛的"保持原格式"）

### 步骤 3：验证效果
- 使用生成的智能提示词验证提取效果，确保规则准确

### 步骤 4：自动积累（新增）
- 验证通过后，AI 生成的新规则自动保存到案例库
- 标记来源为 `ai_generated`，便于后续复用

## 注意事项

- ✅ CSV 需要三列：`要素名称`、`要素提取说明`、`提取规则说明`
- ✅ 提供上下文信息帮助 AI 生成更精准的规则
- ✅ **必须提供图片**：至少一张文档图片用于 AI 分析
- ✅ 必须配置 `DASHSCOPE_API_KEY` 环境变量
- ✅ 支持的图片格式：jpg、jpeg、png、bmp
- ⚠️ 确保图片清晰可读，AI 才能准确分析
- 💡 说明列可以为空，但建议填写以获得更好的结果
- 🗄️ **案例库自动管理**：无需手动编辑 `case_library.json`
- 🚀 **越用越快**：常用要素会优先从案例库匹配，减少 AI 调用
