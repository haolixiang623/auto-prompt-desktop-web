# 要素信息录入JSON生成器

自动为每个材料目录生成对应的要素信息录入JSON文件，用于系统配置和数据录入。

## 核心特性

- ✅ 自动读取Excel中的要素定义
- ✅ 智能提取提示词文件中的识别规则
- ✅ 为每个材料生成独立的JSON配置
- ✅ 自动匹配要素名称与识别提示词
- ✅ 保留JSON格式的可读性（缩进、中文不转义）
- ✅ 支持自定义JSON模板结构

## 快速开始

### 1. 准备工作目录

确保材料集目录包含：
- `factors.xlsx` 文件（定义材料和要素）
- 各材料子目录及对应的提示词TXT文件

### 2. 运行生成脚本

```bash
python3 .windsurf/skills/factor-json-generator/generate_factor_json.py 材料集/
```

### 3. 查看结果

每个材料目录下会生成 `<材料名称>--要素信息录入.json` 文件。

## JSON模板自定义

脚本从 `factor_entry_template.json` 读取JSON结构模板。

**模板位置**：`.windsurf/skills/factor-json-generator/factor_entry_template.json`

**自定义方式**：
- 修改模板文件中的字段名称
- 添加新字段
- 修改默认值
- 调整字段顺序

脚本会自动使用修改后的模板生成JSON文件。

## 生成的JSON格式

```json
[
  {
    "要素名称": "统一社会信用代码",
    "要素用途": "企业的唯一识别码",
    "所属材料": "营业证照",
    "转换类型": "",
    "采集序号": "",
    "是否要素应用": "否",
    "排序": 1,
    "关联字段": "",
    "要素说明": "",
    "要素识别提示词": "在文档中查找由18位字母和数字组成的字符串..."
  }
]
```

## 字段来源

| 字段 | 来源 | 说明 |
|-----|------|------|
| 要素名称 | Excel | 从factors.xlsx第2列读取 |
| 要素用途 | Excel | 从factors.xlsx第3列读取 |
| 所属材料 | Excel | 从factors.xlsx第1列读取 |
| 要素识别提示词 | TXT | 从提示词文件中提取 |
| 排序 | 自动 | 按要素顺序自动编号 |
| 其他字段 | 默认值 | 需后续手动完善 |

## 工作流程

1. 读取 `factors.xlsx` 获取所有材料及其要素定义
2. 遍历每个材料目录
3. 查找材料目录下的提示词TXT文件
4. 从提示词中提取要素识别规则
5. 生成JSON模板并填充数据
6. 保存为 `<材料名称>--要素信息录入.json`

## 注意事项

- 提示词文件必须包含"# 识别要素列表及规则"部分
- Excel中的要素名称必须与提示词中的要素名称完全一致
- 生成的JSON文件会覆盖同名文件
- 部分字段（转换类型、采集序号等）需要后续手动完善
