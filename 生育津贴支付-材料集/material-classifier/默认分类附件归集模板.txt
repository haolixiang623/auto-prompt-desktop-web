根据步骤1的分类信息提取结果，生成最终的附件归集方案。

## 可用材料目录
$(material_list)

## 步骤1分类结果
$(classification_result)

## 任务要求
1. 基于步骤1的分类结果，为每个附件确定最终归集目录
2. 评估分类置信度（high/medium/low）
3. 生成归集执行计划

## 输出格式
请以JSON格式返回，格式如下：
```json
{
  "classification_plan": [
    {
      "file_name": "附件文件名",
      "target_folder": "目标材料目录名称",
      "confidence": "high/medium/low",
      "reason": "归集理由"
    }
  ],
  "summary": {
    "total_files": 0,
    "classified_count": 0,
    "unclassified_count": 0
  }
}
```

## 注意事项
- target_folder 必须严格从上述材料目录列表中选择
- 如果无法确定，使用"其他"
- confidence 用于标识分类的可靠程度
- 每个附件都必须有归集方案
- summary 应准确统计归集情况
