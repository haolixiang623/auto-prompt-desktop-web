# 案例批量导入工具

此 Skill 用于从 `case-collect` 目录批量导入已生成的提示词文件到案例库中。

## 功能说明

自动解析提示词文件（如 `营业证照--要素提取完整提示词.txt`），提取其中的要素规则，并批量添加到 `doc-extract-prompt-gen` 的案例库中。

## 使用场景

- 已有大量手动编写或 AI 生成的提示词文件
- 需要将这些优质规则统一管理到案例库
- 避免重复生成相同的规则

## 目录结构

```
Auto-Prompt/
├── case-collect/                    # 待导入的提示词文件存放目录
│   ├── 营业证照--要素提取完整提示词.txt
│   ├── 公司登记备案申请书--要素提取完整提示词.txt
│   └── ...
└── .windsurf/skills/
    ├── doc-extract-prompt-gen/
    │   └── case_library.json        # 案例库（导入目标）
    └── case-import/
        └── import_cases.py          # 导入脚本
```

## 使用方法

### 1. 准备提示词文件

将要导入的提示词文件复制到 `case-collect` 目录：

```bash
cp 营业证照/营业证照--要素提取完整提示词.txt case-collect/
cp 公司登记备案申请书/公司登记备案申请书--要素提取完整提示词.txt case-collect/
```

### 2. 运行导入脚本

```bash
cd /Users/gooddream/Desktop/projects/Auto-Prompt/.windsurf/skills/case-import
python3 import_cases.py
```

### 3. 查看导入结果

脚本会显示：
- 发现的文件数量
- 每个文件解析出的要素数量
- 新增案例数量
- 跳过的重复案例数量
- 案例库总数

## 提示词文件格式要求

文件必须包含 `# 识别要素列表及规则` 部分，格式如下：

```
# 识别要素列表及规则
## 1.统一社会信用代码
在文档中识别18位由字母和数字组成的字符串...，保持原格式，确保为18位字母数字组合

## 2.企业名称
提取公司完整的法定名称...，保持原格式，确保包含公司类型后缀
```

## 解析规则

- **要素名称**：从 `## 数字.名称` 中提取
- **提取规则**：从要素描述中提取（逗号或句号前的部分）
- **格式要求**：从要素描述中提取（最后一个逗号或句号后的部分）
- **标签**：根据文件名自动识别（如"营业执照"→["企业信息", "营业执照", "证照"]）
- **来源**：标记为 `imported`

## 去重机制

- 如果案例库中已存在相同要素名称和规则，则跳过
- 避免重复导入相同的案例

## 注意事项

- ✅ 案例库文件统一保存在 `doc-extract-prompt-gen` skill 目录
- ✅ 支持批量导入多个提示词文件
- ✅ 自动去重，避免重复案例
- ✅ 根据文件名自动添加标签
- ⚠️ 确保提示词文件格式正确，否则可能解析失败
- 💡 导入后的案例可在 `doc-extract-prompt-gen` 中直接使用
