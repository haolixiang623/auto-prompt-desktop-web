# Case Import Skill

批量导入提示词文件到案例库的工具。

## 快速开始

1. 将提示词文件复制到 `case-collect` 目录
2. 运行导入脚本：
   ```bash
   cd .windsurf/skills/case-import
   python3 import_cases.py
   ```

## 功能特性

- ✅ 自动解析提示词文件中的要素规则
- ✅ 批量导入到统一案例库
- ✅ 智能去重，避免重复案例
- ✅ 根据文件名自动添加标签
- ✅ 标记来源为 `imported`
